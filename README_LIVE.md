# Hextris 直播功能使用说明

## 功能介绍

Hextris游戏现在支持完整的直播功能，包括：

1. **主播功能**：创建直播房间，生成6位数字房间号，实时同步游戏画面和状态
2. **观众功能**：浏览直播大厅，观看任意主播的实时游戏画面
3. **弹幕互动**：观众可以发送文字弹幕，与主播和其他观众互动
4. **实时同步**：游戏画面延迟不超过2秒，确保观众看到的画面与主播完全同步

## 系统要求

- Python 3.7+（用于运行WebSocket服务器）
- 现代浏览器（支持WebSocket API）

## 安装和运行

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 2. 启动WebSocket服务器

```bash
python server.py
```

服务器将在 `ws://localhost:8765` 启动

### 3. 启动游戏

在浏览器中打开 `index.html` 文件即可开始游戏

## 使用说明

### 作为主播

1. 打开游戏后，点击右上角的"开始直播"按钮
2. 输入您的昵称（可选），然后点击确定
3. 系统将自动创建一个直播房间并生成6位数字房间号
4. "开始直播"按钮会变为"停止直播"，同时显示房间号
5. 开始游戏，您的游戏画面将实时同步给所有观众
6. 点击"停止直播"按钮可以结束直播，所有观众将自动退出

### 作为观众

1. 打开游戏后，点击右上角的"观看直播"按钮
2. 在直播大厅中，您可以看到所有正在直播的房间列表
3. 每个房间显示：房间号、主播昵称、当前分数、观看人数
4. 点击任意房间即可进入观看模式
5. 在观看界面，您可以看到主播的实时游戏画面和直播信息
6. 在底部输入框中输入文字，点击"发送"或按回车键即可发送弹幕
7. 点击"返回大厅"按钮可以回到直播大厅

## 功能特性

### 实时游戏同步
- 游戏状态每100ms更新一次，延迟不超过2秒
- 同步内容包括：方块位置、颜色、分数、游戏时间、组合时间等

### 弹幕系统
- 最多同时显示10条弹幕
- 弹幕从右侧滑入，支持滚动查看
- 每条弹幕显示发送者昵称和内容

### 房间管理
- 自动生成6位数字房间号
- 支持多个房间同时直播
- 主播离开后房间自动关闭
- 观众实时数量统计

## 技术架构

### 后端（Python）
- 使用 `websockets` 库实现WebSocket通信
- 支持房间管理、状态同步、弹幕广播
- 并发连接处理

### 前端（JavaScript）
- WebSocket客户端连接
- 游戏状态收集和发送
- 直播画面渲染
- 弹幕显示和交互

## 常见问题

**Q: 无法连接到服务器**
A: 请确保WebSocket服务器已经启动，并且地址是 `ws://localhost:8765`

**Q: 直播画面延迟高**
A: 检查网络连接，确保没有防火墙或代理阻止WebSocket连接

**Q: 弹幕不显示**
A: 确保已经正确连接到房间，并且输入内容不为空

**Q: 房间号无效**
A: 房间号可能已经过期或主播已经结束直播，请尝试其他房间
