# Hextris 直播功能使用说明

## 概述

Hextris 现在支持实时直播功能！玩家可以创建直播房间，其他玩家可以观看直播并进行互动。

## 功能特性

### 主播功能
- 点击"开始直播"按钮创建直播房间
- 系统生成6位唯一房间号
- 直播过程中可以随时点击"停止直播"结束直播
- 直播界面显示房间号和观众人数
- 可以发送聊天消息与观众互动

### 观众功能
- 点击"观看直播"按钮进入直播大厅
- 查看当前所有正在直播的房间列表
- 点击任意房间进入观看界面
- 实时观看主播的游戏画面（延迟不超过2秒）
- 查看主播的实时分数、游戏时长和观众人数
- 发送文字弹幕与主播和其他观众互动

## 技术实现

### 服务器端
- 使用 Python 3.7+ 和 websockets 库实现
- 支持多房间同时直播
- 实时数据传输，延迟低

### 客户端
- 使用 WebSocket 进行实时通信
- 游戏画面实时同步
- 弹幕系统支持最多同时显示10条消息

## 安装和运行

### 1. 安装 Python 依赖

```bash
pip install websockets
```

### 2. 启动直播服务器

```bash
python server.py
```

服务器将在 `localhost:8765` 启动。

### 3. 启动游戏

在浏览器中打开 `index.html` 文件即可开始游戏。

## 使用说明

### 作为主播

1. 打开游戏，点击主菜单或游戏界面左上角的"开始直播"按钮
2. 在弹出的对话框中输入您的昵称，点击确定
3. 系统将创建一个直播房间并显示房间号
4. 开始游戏，其他玩家可以通过房间号观看您的直播
5. 直播过程中，您可以点击"停止直播"按钮结束直播

### 作为观众

1. 打开游戏，点击主菜单的"观看直播"按钮
2. 在直播大厅中查看当前所有直播房间
3. 点击任意房间进入观看界面
4. 观看直播过程中，您可以在右侧聊天框中发送消息
5. 点击"离开直播"按钮返回主菜单

## 注意事项

1. 确保直播服务器已启动，否则无法创建或加入直播房间
2. 直播功能需要浏览器支持 WebSocket
3. 建议使用现代浏览器（Chrome、Firefox、Safari、Edge）以获得最佳体验
4. 直播过程中请保持网络连接稳定

## 故障排除

### 无法连接到服务器
- 确保 `server.py` 已正确启动
- 检查防火墙设置，确保端口 8765 已开放
- 确保浏览器支持 WebSocket

### 直播画面延迟过高
- 检查网络连接速度
- 关闭其他占用网络带宽的应用程序

### 无法发送或接收聊天消息
- 确保网络连接正常
- 刷新页面重试

## 开发说明

### 服务器代码结构

- `server.py` - 主服务器文件，处理 WebSocket 连接和房间管理

### 客户端代码结构

- `js/broadcast.js` - 直播功能的核心逻辑
- `index.html` - 添加了直播相关的 UI 元素
- `style/style.css` - 添加了直播相关的样式

### 主要类和方法

#### broadcastModule (客户端)
- `init()` - 初始化直播模块
- `startBroadcast()` - 开始直播
- `stopBroadcast()` - 停止直播
- `showBroadcastLobby()` - 显示直播大厅
- `joinBroadcast(roomId)` - 加入指定房间
- `leaveBroadcast()` - 离开当前直播
- `sendChatMessage()` - 发送聊天消息

#### 服务器端处理函数
- `handle_connection()` - 处理新的 WebSocket 连接
- `handle_host()` - 处理主播连接
- `handle_viewer()` - 处理观众连接
- `broadcast_to_viewers()` - 向房间内所有观众广播消息
